# IT Services Portal (ITSM Platform)

This project is a single-page web application for an **IT Service Management (ITSM) & Service Desk Platform**.

## Features Included
- **Dashboard**: Live system metrics for tickets and assets.
- **Service Catalog**: Quick request options for enterprise hardware & permissions.
- **Ticket Management**: Create, view, and resolve support tickets.
- **Asset Management**: Track company hardware inventory.
- **Knowledge Base**: Interactive FAQ section.
- **Responsive Layout**: Built for mobile and desktop screens.
- **Persistence**: Built-in LocalStorage integration.

## Getting Started
1. Clone or download this repository.
2. Open `index.html` in any modern web browser.
