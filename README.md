# ITServicePro - IT Services Portal (ITSM Platform)

**Task ID:** WD-SW-002  
**Domain:** IT Services & Technology  
**Project:** IT Service Management (ITSM) & Service Desk Platform  

---

## 🚀 Overview
**ITServicePro** is a comprehensive, production-ready frontend IT Service Management (ITSM) web portal. It provides a centralized dashboard for IT service delivery, support ticket management, service requests, hardware/software asset management, client administration, knowledge base articles, and service analytics.

---

## 🛠️ Included Modules & Features
- **Dashboard**: High-level service statistics, recent activity log, and SLA compliance metrics.
- **Service Catalog**: IT services list with descriptions, pricing, and SLA timeframes.
- **Ticket Management**: Full CRUD capabilities for support tickets with priority levels (`Critical`, `High`, `Medium`, `Low`, `Informational`).
- **Service Requests**: Dedicated portal for software installation and hardware setup requests.
- **Asset Management**: Complete inventory for hardware, software licenses, and network devices.
- **Client Management**: Track enterprise client profiles, contact points, and phone numbers.
- **Knowledge Base**: Live keyword search across troubleshooting articles and FAQs.
- **Reports & Analytics**: Visual ticket priority distribution and resolution performance indicators.
- **Login / Register**: Role switching mechanism (Admin, Technician, Client).
